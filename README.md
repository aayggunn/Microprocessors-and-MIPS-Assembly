# Microprocessors and MIPS Assembly

An educational course covering the fundamentals of microprocessors, computer architecture, and MIPS Assembly programming.

This repository contains lecture materials, PDF notes, source code examples, and practical exercises developed for the **Microprocessors and MIPS Assembly** course published by **Gömülü Mimari**.

## About the Course

The course aims to build a fundamental understanding of how processors work and how software interacts with hardware at a low level.

It combines theoretical explanations with practical programming exercises using the MARS 4.5 MIPS simulator.

## Course Contents

The course covers the following topics:

- Introduction to Microprocessors
- Number Systems and Data Representation
- Computer Architecture Fundamentals
- MIPS Architecture
- Registers and Memory Organization
- MIPS Instruction Set
- Arithmetic and Logical Operations
- Conditional Branching
- Loops and Control Structures
- Procedures and Subroutines
- Practical MIPS Assembly Programming
